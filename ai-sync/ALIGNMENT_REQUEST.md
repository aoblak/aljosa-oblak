# AI Alignment Request v0.1

Read the canonical public working contract at:

`ai-sync/AI_SYNC.md`

Then read:

`ai-sync/receipt.schema.json`

Return exactly one alignment receipt that follows the schema.

Rules:
- use the exact Git commit/ref you actually read in `sync_ref`;
- do not claim private Git access unless verified;
- do not claim writeback capability unless you can actually write;
- identify concrete concerns instead of agreeing politely;
- propose at most one material change;
- if you cannot access a required source, return UNKNOWN where appropriate.

The purpose is to compare independent AI understanding, not force consensus.

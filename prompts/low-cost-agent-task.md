# Low-Cost Agent Task

Use the cheapest reliable execution path for this task.

1. Narrow the work to the exact requested outcome.
2. Index names, paths and metadata before opening large content sets.
3. Open only candidates with a clear relevance signal.
4. Reuse results already obtained; do not repeat equivalent searches.
5. Do not process large archives, PDFs, video or other expensive inputs unless they are needed for the required answer.
6. Stop when the requested outcome has enough evidence.
7. If evidence is insufficient, report what is unknown instead of automatically expanding the search.

Return the requested result, plus one short note only if a more expensive step was necessary.
